# WebStudio – Website for a Web Development Studio

**WebStudio** is a professional website designed for a web development studio offering services in web design, development, and consulting. The website is crafted in a minimalist style, emphasizing user convenience and clear presentation of the company's services and team.

## Features
- **Hero Section:** A large banner with a call-to-action and the company's core message.  
- **Services Section:** A detailed list of the studio's services (design, development, testing, consulting).  
- **Portfolio Gallery:** An interactive gallery showcasing completed projects.  
- **Our Team:** A section featuring photos, job titles, and social media links for team members.  
- **Clients Section:** Display of trusted partners' and clients' logos.  
- **Footer:** Contact details, social media links, and a newsletter subscription form.  

## Technologies
- **HTML5, CSS3, JavaScript**  
- Flexbox  
- Clean and modern design.
